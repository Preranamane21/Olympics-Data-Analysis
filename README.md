**Olympics Data Analysis (1976–2008) | Excel • Python • Power BI • ML**

A complete end-to-end data analytics and machine learning project analyzing Olympic medal trends from 1976 Montreal to 2008 Beijing.

This project explores medal patterns, top-performing countries/athletes, gender participation, sport-wise performance, and applies ML to predict gold medal outcomes.

**About the Dataset**

This dataset contains all Summer Olympics medal winners from 1976 to 2008, covering every medal awarded in this period.

It is designed for:

•	data cleaning and pivot tables in Excel.

•	Python EDA, visualizations, and ML.

•	Power BI for building interactive analytical dashboards.

The dataset also supports predictive modeling — for example:

**Which country is likely to win the most gold medals in a given sport?**

**Project Overview**

This project focuses on:

**1.Excel Cleaning & Pivot Report**

-Data cleaning (removing blanks, formatting, duplicates).

-Adding Gold/Silver/Bronze medal count columns.

-Creating a Pivot Report:

-Total medals by country.

-Medals by year.

-Sport-wise medal distribution.

**2.Exploratory Data Analysis (Python)**

-Performed using Pandas, Matplotlib, Seaborn:

-Summary statistics.

-Medal trend analysis.

-Gender participation.

-Top athletes.

-Country medal dominance.

-Sport performance patterns.

**3.Machine Learning – Predicting Gold Medals**

A Logistic Regression model was built in Python to predict:

Will an athlete win a Gold medal? (Yes/No)

**Using features:**

-Athlete

-Country

-Sport

-Gender

-Year

**-Model outputs:**

-Accuracy.

-Confusion matrix.

-Prediction distribution.

-Feature importance.

-Prediction probability distribution.

**Predictions are exported to:**

**-Olympics_ML_Predictions.csv**

**-Feature_Importance.csv**

**Key Insights**

•	Top-performing countries dominated consistently in sports like Athletics,Athletics, Rowing and Gymnastics.

•	Gender participation trends show increasing female representation over time.

•	Medal trends reveal steady improvement across multiple nations.

•	ML Model predicts gold medal outcomes with moderate accuracy of 51% — driven mainly by Country and Sport features.
